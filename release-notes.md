## What's new
- **Start Spine when you log in.** Settings → Updates & window → Start with your PC → On. Spine then opens by itself when you turn on your PC, like a console. Turn on Fullscreen too for the full effect. Works on Windows and Linux; if you switch it off in Task Manager or Startup Applications, Spine sees that too.

From 0.26.1:
- With no video player installed, Spine now suggests mpv (with a one-click **Get mpv** on Windows).

---

**Windows:** download **Spine-Setup.exe** below and run it. No admin rights needed.

**Linux:** run `curl -fsSL https://raw.githubusercontent.com/paperwolf2350-lab/spine/main/install.sh | sh`, or download **Spine-x86_64.AppImage**, allow it to run as a program (right-click → Properties → Permissions), and open it. Debian/Ubuntu/Mint: **Spine-amd64.deb**.

Already have Spine? It updates itself from Settings → Updates.
