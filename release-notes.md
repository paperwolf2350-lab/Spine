## What's new
- **Movies inside show folders** (like Jujutsu Kaisen 0 or Goblin's Crown) now get their real title, year, length, summary and a picture from TMDB.
- **Fix match:** if one comes out wrong or missing, open the show's "Movies & specials" tab, press **Fix match**, type its English title and search again.
- Since 0.6.1: Season 2 details for shows TMDB lists as one long season, and "Which season is this?" for arcs.

---

**Windows:** download **Spine-Setup.exe** below and run it. No admin rights needed.

**Linux:** run `curl -fsSL https://raw.githubusercontent.com/paperwolf2350-lab/spine/main/install.sh | sh`, or download **Spine-x86_64.AppImage**, allow it to run as a program (right-click → Properties → Permissions), and open it. Debian/Ubuntu/Mint: **Spine-amd64.deb**.

Already have Spine? It updates itself from Settings → Updates.
