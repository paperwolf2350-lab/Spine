## What's new
- Spine for Linux: one AppImage that adds itself to your app menu and updates itself, plus a .deb.
- On Linux, Spine finds Flatpak emulators, AppImages in ~/Applications (EmuDeck), and installed ones.
- Steam (including the Flatpak) and Heroic (Epic and GOG) games show up in PC Games on Linux.
- Game pages say what opens a PC game: Steam, Heroic, Epic Games or your PC.

---

**Windows:** download **Spine-Setup.exe** below and run it. No admin rights needed.

**Linux:** run `curl -fsSL https://raw.githubusercontent.com/paperwolf2350-lab/spine/main/install.sh | sh`, or download **Spine-x86_64.AppImage**, allow it to run as a program (right-click → Properties → Permissions), and open it. Debian/Ubuntu: **Spine-amd64.deb**.

Already have Spine? It updates itself from Settings → Updates.
