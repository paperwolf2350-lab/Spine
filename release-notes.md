## What's new
- **Movies (first test version).** Settings → Movies → Add movie folder. Your films show up as a Movies shelf on Home, sorted A–Z like the games, and play in VLC or mpv (whichever you have installed).
- Posters, banners, descriptions, year, length and genres come from TMDB. Add your free TMDB key in Settings → Scrapers.
- TV shows aren't in yet: episode files (S01E02) and "Season" folders are skipped for now.

---

**Windows:** download **Spine-Setup.exe** below and run it. No admin rights needed.

**Linux:** run `curl -fsSL https://raw.githubusercontent.com/paperwolf2350-lab/spine/main/install.sh | sh`, or download **Spine-x86_64.AppImage**, allow it to run as a program (right-click → Properties → Permissions), and open it. Debian/Ubuntu/Mint: **Spine-amd64.deb**.

Already have Spine? It updates itself from Settings → Updates.
