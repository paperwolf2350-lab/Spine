## What's new
- Console games get many more descriptions: Spine now removes ranking numbers like "02. " from file names before asking ScreenScraper, sends each ROM's checksum, and searches by name when a file isn't recognized. Games that weren't found before are looked up again automatically.
- PC games get descriptions, release years, genres and developers from Steam's store (since 0.4.2).

---

**Windows:** download **Spine-Setup.exe** below and run it. No admin rights needed.

**Linux:** run `curl -fsSL https://raw.githubusercontent.com/paperwolf2350-lab/spine/main/install.sh | sh`, or download **Spine-x86_64.AppImage**, allow it to run as a program (right-click → Properties → Permissions), and open it. Debian/Ubuntu/Mint: **Spine-amd64.deb**.

Already have Spine? It updates itself from Settings → Updates.
