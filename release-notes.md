## What's new
- **Points you to the right player.** With neither mpv nor VLC installed, opening a movie or episode now suggests mpv (Spine's own player, with resume, Skip intro and Up next) instead of VLC. On Windows that comes with the **Get mpv** button, so it's one click.

From 0.26.0:
- New console icons from RetroArch's "Monochrome" set (or "Systematic", or Spine's old "Lines"), Settings → Look → Console icons.

---

**Windows:** download **Spine-Setup.exe** below and run it. No admin rights needed.

**Linux:** run `curl -fsSL https://raw.githubusercontent.com/paperwolf2350-lab/spine/main/install.sh | sh`, or download **Spine-x86_64.AppImage**, allow it to run as a program (right-click → Properties → Permissions), and open it. Debian/Ubuntu/Mint: **Spine-amd64.deb**.

Already have Spine? It updates itself from Settings → Updates.
